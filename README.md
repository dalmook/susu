# 수수께끼 놀이터

초등학교 1학년이 즐겁게 풀 수 있는 모바일 중심 수수께끼 웹사이트입니다.

- 부모님이 문제·힌트·정답을 차례대로 보여 주는 **같이 문제 내기**
- 아이가 보기 3개 중 정답을 고르는 **혼자 도전하기**
- 분야·난이도 선택, 문제 검색, 점수와 별, 축하 효과
- 한국어 읽어주기, 휴대전화·태블릿·PC 반응형 화면
- 브라우저에서 새 문제 추가, JSON 가져오기·내보내기

## 문제 데이터 구조

기본 문제는 `data/riddles.json` 한 파일에서 관리합니다. 현재 175문제가 들어 있으며, 앱은 일반 JSON과 `gzip-base64` 압축 형식을 모두 읽을 수 있습니다.

각 문제는 아래 필드를 사용합니다.

```json
{
  "id": "animal-001",
  "category": "동물",
  "difficulty": 1,
  "emoji": "🐘",
  "question": "코가 손처럼 길어서 물건도 집는 동물은?",
  "answer": "코끼리",
  "hint": "몸집이 아주 크고 귀도 커요.",
  "explanation": "코끼리는 긴 코로 먹이와 물건을 집을 수 있어요."
}
```

사용 가능한 분야는 `동물`, `음식`, `학교`, `생활`, `자연`, `말놀이`, `생각`입니다. 난이도는 `1`이 쉬움, `2`가 조금 생각입니다.

## 앞으로 문제를 업데이트할 때

1. 기존 문제와 같은 표현이 있는지 먼저 확인합니다.
2. 초등학교 1학년이 이해하기 어려운 한자·외국 지명·옛말은 피합니다.
3. 문제마다 답이 하나로 분명한지 확인합니다.
4. `id`는 기존 값과 겹치지 않게 만듭니다.
5. 데이터의 `meta.dataVersion`과 `meta.total`을 갱신합니다.
6. 변경 후 모바일에서 같이 문제 내기와 혼자 도전하기를 각각 시험합니다.

사이트 오른쪽 위 ⚙️에서 넣은 문제는 해당 기기의 브라우저에만 저장됩니다. 보관하거나 다른 기기로 옮길 때는 **JSON 내보내기**를 사용합니다.

## 콘텐츠 원칙

외부 수수께끼 사이트의 전체 문장을 그대로 복제하지 않고, 초등학교 1학년 눈높이에 맞춰 새로 작성하거나 일반적인 소재를 독자적으로 다듬어 사용합니다. 이후 추가되는 문제도 같은 원칙으로 관리합니다.

## 로컬 실행

파일을 직접 열면 브라우저 보안 정책 때문에 데이터 로딩이 막힐 수 있으므로 간단한 웹 서버로 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.
